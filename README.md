✅ Spell Checker App using Python (CLI-Based)
📌 Project Description:
Spell Checker Application built using the pyspellchecker library in Python. It allows users to input a block of text, automatically detect spelling mistakes, and suggest corrections for each incorrect word. This tool is especially useful for writers, students, or anyone looking to quickly validate text spelling from the terminal.

🚀 Key Features:
Text Input – Accepts user input from the command line.
Spell Checking – Identifies and suggests corrections for misspelled words.
Auto Correction – Automatically replaces wrong words with the most probable correct spelling.
Correction Feedback – Shows which words were corrected and their replacements.
Loop Until Exit – Keeps running until the user types "exit".

🛠️ Technologies Used:
Python 3.x
pyspellchecker library
